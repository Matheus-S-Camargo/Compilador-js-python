Demarcação Factual de Arquitetura
Fato Verificado no Código: O pipeline oficial executado via Makefile e src/main.c conecta a entrada JavaScript ao analisador léxico Flex (lexico.l), analisa as produções sintáticas no Bison (grammar.y), gera os nós da AST (ast.c) e transcreve o código para Python (gerador.c).

Ponto de Evolução Identificado: O módulo src/tabela.c implementa uma pilha completa de tabelas de símbolos (escopo, identificadores, tipos e flags de constante) com testes unitários em tests/teste_tabela.c, servindo de base para validações semânticas adicionais.
